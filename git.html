Git

  • Git is used to manage and save files.
  • Git is capable of managing versions of source code or data.
  • It is used by programmers who are developing software collaboratively.

Git commands are used to interact with Git, a distributed version control system. They allow users to manage code changes, track history, and collaborate on projects. Here are some of the most commonly used Git commands:

Command Purpose
git init Initializes a new Git repository in the current directory.
git clone <repository-url> Creates a local copy of an existing remote repository.
git status Shows the current state of the working directory and staging area.
git add <file> Stages changes in a specific file for the next commit. git add . stages all changes.
git log Displays the commit history of the branch.

Step-by-Step Guide: How to Set Up Git

  • Download Git: Visit git-scm.com and download the installer for your OS.
  • Install Git: Run the installer and follow the default setup. Choose Git Bash as your terminal.
  • Verify Installation: Open your terminal and run git --version to confirm Git is installed.
  • Set Your Identity:
    git config --global user.name "Your Name"
    git config --global user.email "you@example.com"
  • Create a Repository: Navigate to your project folder and run git init.
  • Make Your First Commit:
    git add .
    git commit -m "Initial commit"
  • Connect to Remote:
    git remote add origin https://github.com/your-repo.git
    git push -u origin master
