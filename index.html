HyperText Markup Language (HTML)

  • HyperText Markup Language, also known as HTML, is used to create and design the structure of web pages.
  • It defines the meaning and structure of a web page.
  • Can display text, images, links, videos, and form.
  • Every HTML document starts with a <!DOCTYPE html> declaration.
  • You can view and edit HTML code using a text editor like Visual Studio Code.

What is Basic Tags?

Basic HTML tags are the foundational elements used to structure and display content on a web page. They define everything from headings and paragraphs to links, images, and layout sections.

Basic Tags - DOCUMENT STRUCTURE

Tag Description
<!DOCTYPE html> Defines the HTML version
<head> Contains meta info
<html> Root element of the page
<body> Main content area

Basic Tags - TABLE

Tag Description
<table> Used to create a table in a webpage
<tr> It defines a single row in a table
<th> It defines a header cell (like a column title)
<td> Table data cell

Basic Tags - LAYOUT

Tag Description
<div> Defines a division or section
<span> Inline container

Basic Tags - TEXT AND CONTENT

Tag Description
<img src="" alt=""> <img> stands for image, and it’s used to display pictures on a webpage
<p> Used for paragraphs
<br> Line break
<strong> Bold text
<em> Italic text
<hr> Horizontal line

Example:

<p><em>This is an italic text.</em><strong> This is a bold text.</strong></p>

Output: This is an italic text. This is a bold text.

Basic Tags - LISTS

Tag Description
<ul> Unordered list (bullet points)
<ol> Ordered list (numbered)
<li> List item

Example:

This is an unordered list:

  • First item
  • Second item
  • Third item

Basic Tags - FORMS

Tag Description
<form> Used to create an HTML form for user input
<input> Used to create an input field
<text area> Used to create a multi-line text input
<button> Used to create a clickable button
<label> Used to create a label for an input element

How to Add a Different Page and a Button?

Adding a new page and a button is simple. You just need to create a new HTML file for the page and add a button element in the desired location.


For example, to create a new page called "index.html", you would create a new file named "index.html" and add the necessary HTML structure. To add a button, you can use the <button> tag.
