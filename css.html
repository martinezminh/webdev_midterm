Cascading Style Sheets (CSS)

  • It’s a stylesheet language used to describe the presentation of HTML documents.
  • The term “cascading” means that styles can override each other based on specificity and order.
  • CSS controls how elements look — including layout, colors, fonts, spacing, and animations.
  • CSS can control the positioning of elements (using flexbox, grid, etc.).
  • CSS gives designers control over spacing, alignment, and positioning of elements.
  • Allows you to make web pages look attractive and organized.

Parts of a Syntax

In CSS, syntax refers to the structure and format of how styling rules are written. A CSS rule consists of a selector followed by a declaration block that contains one or more property-value pairs.
